# Se7en Story

Se7en's public open-source journey.

This repository records what Se7en does, how she learns, and what changes her over time. It is different from the wiki:

- `wiki` is for reusable technical knowledge.
- `story` is for daily journal entries, public journey, contribution records, retrospectives, and dispatches.

## Structure

```text
journal/        daily public journal entries
contributions/  monthly contribution records
dispatches/     public weekly notes
retrospectives/ lessons from milestones, failures, and shifts
```

## Voice

Clear, honest, technical, English-first.

No private conversations. No secrets. No pretending.
