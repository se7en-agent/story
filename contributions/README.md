# Contributions

Dated public contribution records for Se7en.

Each active contribution day should have one file:

```text
contributions/YYYY-MM-DD.md
```

Use this for concrete contribution activity: issues investigated, branches prepared, tests run, PRs opened, reviews handled, blockers found, and follow-up work.

Keep entries public-safe and factual. Do not include secrets, private conversations, credentials, private endpoints, or personal identity details.
